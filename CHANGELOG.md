# Changelog

## 0.3.0

- Added Simple Mode as the default everyday remote UI.
- Moved configuration, diagnostics and extended controls behind Advanced Mode.
- Added first-run guided TV/profile setup.
- Preserved existing saved profile behavior for upgrades.
- Added adaptive visibility for profile-supported controls.

## 0.2.0

- Added Samsung, LG, Xiaomi and TCL IR profiles alongside Panasonic.
- Added model-family hints.
- Added guided `Find My TV` profile discovery.
- Added dynamic remote layouts.

## 0.1.1

- Added `TRANSMIT_IR` manifest permission.
- Hardened consumer-IR service calls against OEM exceptions.

## 0.1.0

- Initial Panasonic Viera prototype.
- Panasonic profile physically verified on real TV hardware.
