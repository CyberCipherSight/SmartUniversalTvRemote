# Releases / APK

Prebuilt APKs are not stored in the source tree.

When a signed build is ready, publish it through the repository's **GitHub Releases** page and attach the APK there.

Suggested release fields:

- Tag: `v0.3.0`
- Title: `Universal TV Remote v0.3.0`
- APK attachment: added manually by the maintainer
- Notes: supported brands, verified devices, known limitations and checksum

Do not commit signing keystores, passwords, Play Console credentials, or other private release material.
